# 🎵 Music Player - CodeAlpha Task 3

A simple and interactive Music Player developed using **HTML, CSS, and JavaScript** as part of the **CodeAlpha Frontend Development Internship**.

## 📌 Project Overview

This Music Player allows users to play their favorite songs through a clean and user-friendly interface. It provides essential music playback controls to enhance the listening experience.

## ✨ Features

- ▶️ Play and Pause songs
- ⏭️ Next track functionality
- ⏮️ Previous track functionality
- 🔊 Volume control
- 📃 Display of song information
- 🎶 Playlist support
- 📱 Responsive design for different screen sizes
- 🎨 Simple and attractive user interface

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Music player functionality and interactivity
